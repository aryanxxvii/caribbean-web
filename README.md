# Caribbean Web

Read-only edition of Caribbean. Search and filter the film library, browse shelves, and view film details, technical specs, and saved watched status.

This repository contains the built static site. Serve its root with any static web host. On page load, the site fetches the [public library JSON](https://raw.githubusercontent.com/aryanxxvii/carribean-library/refs/heads/carribean-library/carribean-library.json) directly from GitHub. No backend, credentials, or environment variables are required.
